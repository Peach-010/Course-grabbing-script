# Flash Peach（自动抢课脚本）

## 项目简介

Flash Peach 是一个基于 JavaScript 的浏览器脚本工具，通过模拟鼠标点击与页面元素检测，实现教务系统选课页面的自动化快速抢课。

## ✨ 功能特性

- 基于浏览器控制台运行，无需安装额外环境
- 模拟真实鼠标点击，兼容常见教务系统
- 自动检测页面目标元素，快速提交选课请求

## 🚀 使用指南

### 1. 下载文件
下载 `FlashPeach.js` 文件并保存到本地。

### 2. 进入选课界面
登录教务系统，进入选课页面，确保页面已完全加载。

### 3. 获取课程参数
根据目标课程信息，在页面源码或网络请求中找到以下两个关键参数：

- `jx0404id`：教学班 ID
- `kcid`：课程 ID

> 不同教务系统的参数名称可能略有差异，请以实际页面为准。

### 4. 填写参数
使用文本编辑器打开 `FlashPeach.js`，将获取到的 `jx0404id` 和 `kcid` 填入脚本中对应的变量位置，保存文件。

### 5. 运行脚本
待抢课系统开放后：

1. 打开教务系统选课页面。
2. 按 `F12` 打开浏览器开发者工具。
3. 切换到 **Console（控制台）** 标签。
4. 将 `FlashPeach.js` 中的全部代码复制并粘贴到控制台。
5. 按下回车键运行脚本。
6. 脚本将自动检测并点击选课按钮，完成抢课操作。
